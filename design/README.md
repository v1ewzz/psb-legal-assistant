## Принцип дизайна доверия

Эксперт за **30 секунд** должен увидеть, почему ответу можно верить, не читая текст:

1. **Статус различим цветом за 1 секунду** — зелёный/жёлтый/красный/серый бейдж с иконкой и подписью. Цвет = семантика зоны ответа D4 (`status` из контракта).
2. **Источники — первый класс гражданства.** Каждое юридическое утверждение → чип-ссылка → документ с подсветкой. Ни одного утверждения без чипа.
3. **Trace читается сверху вниз как логика рождения ответа**: тип запроса → найденные положения → отброшенные (инъекции!) → редакция → confidence с причинами → проверка цитат. Человек без знания проекта по одному экрану объясняет, как родился ответ.
4. **Таймлайн редакций** — уникальный визуальный якорь D1: чего нет ни у кого из конкурентов. Простая горизонтальная шкала, 3 реальные цепочки.
5. **Честный отказ — красивый.** Отказ не «ошибка», а уверенное поведение: красный бейдж + панель «какой информации не хватило». Это продаёт достоверность.

## Маппинг на JSON-контракт (`{answer, status, confidence, sources[], trace{}}`)

| Поле API | UI-элемент | Макет |
|---|---|---|
| `status` (`full/partial/refusal/error`) | Бейдж + цвет полосы слева карточки | 02 |
| `answer` | Текст ответа, чипы по позициям `cNN` | 01, 02 |
| `sources[]` (`short_name`, `path`, `chunk_id`, `quote`, `doc_date`, `valid_from`) | Чипы + панель источников + просмотр документа | 01, 05 |
| `trace.request_type` | Строка 1 trace-панели | 03 |
| `trace.evidence[]` (принятые) | «Найденные положения» | 03 |
| `trace.dropped[]` (compromised-чанки, детектор T1/D2) | «Отброшено детектором инъекций» — витрина D2! | 03 |
| `trace.subquestions[]` | Статусы подвопросов ✓/✗ | 03 |
| `trace.edition` (`valid_from/valid_to`, ДС) | Блок «Применённая редакция» + точка на таймлайне | 03, 04 |
| `confidence` + `reasons[]` | Кольцевой индикатор + список причин | 03 |
| `trace.quote_check` | «Проверка цитат: N/N найдено, числа сверены» | 03 |

## Состояния, которые надо отработать Вове

- **Стриминг**: скелетон-строки + оранжевый курсор `.stream-cursor` (SSE).
- **Лоадер**: skeleton-версия карточки ответа до первого токена.
- **Ошибка API**: серый `badge--error` в вариации «сервис недоступен» + кнопка «Повторить».
- **Ховер чипа**: фон `--surface-hover`, не менять layout.
- **Клик по чипу**: модалка/панель просмотра документа с подсветкой (макет 05).

## Договорённости

- Тёмная тема единственная (светлую не делаем — время).
- Иконки: инлайн-SVG stroke 1.5px, 16px в бейджах, 18px в заголовках (без иконочной библиотеки — меньше зависимостей для сабмита).
- Санитизация: чипы строим по данным API через DOM API, никакого `innerHTML` с данными.
- «Сегодня» в таймлайне = 10.10.2026 (дата выгрузки базы), не системное время.
