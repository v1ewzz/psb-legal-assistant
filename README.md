# ПСБ · Юридический ассистент

RAG-ассистент по закрытой базе нормативных документов (13 федеральных законов +
8 внутренних документов компании ООО «Меридиан», 21 TXT-файл) для
**Hack&Change 2026**, трек AI от ПСБ.

Ассистент:
1. находит положения, в том числе из нескольких источников и диалогового контекста;
2. отвечает со ссылками на конкретные пункты/части и подсветкой фрагмента;
3. обоснованно отказывается, если данных нет, и **не** отказывается, если ответ в базе есть;
4. различает: нехватку данных, ложную предпосылку в вопросе, редакции документов на дату события, врезки-инъекции;
5. показывает экспертам трассу «Как принято решение»: запрос → положения → редакция → уверенность с причинами → проверка цитат.

**Презентация проекта:** `presentation.pdf` (корень репозитория).

```bash
# 2. базовый сценарий

# 3. ловушки

```

Без ключей API веб-чат работает в оффлайн-режиме (экстрактивные ответы по
найденным положениям) — интерфейс и трасса проверяются без LLM.

## Архитектура

Конвейер одного вопроса — `pipeline.answer_one` (одно ядро для batch и web):

```
parse_dialog → Retrieve (BM25 + doc2query, RRF, sibling-fill)
             → Evidence ≤4000 симв. (фрагменты по пунктам)
             → LLM (DeepSeek V4.1 Flash, один вызов)
             → Verify v2 → Render (детерминированный) → зона ответа
```

| Компонент | Что делает |
|---|---|
| `retrieval.py` | каналы exact-ref / BM25 (+doc2query-поле) → RRF → расширение (sibling-пункты того же документа) |
| `ingest.py` | парсеры базы, чанкинг по пунктам, `--build-index`; doc2query-поле индекса |
| `pipeline.py` | общий путь ответа: evidence, промпт, verify, ретраи, fallback |
| `guard.py` | парсер диалога, детектор инъекций (T1) |
| `llm_client.py` | chat/embed/rerank, ретраи, тайм-ауты, repair JSON |
| `webapp.py` | FastAPI + SSE: статусы, источники с подсветкой, трасса, таймлайн редакций |

### Рычаги доверия (флаги, все по умолчанию ON)

| Флаг | Рычаг |
|---|---|
| `REFUSAL_RETRY` | ретрай при переотказе, если точный поиск реквизитов нашёл положения по теме |
| `MISSING_NORM` | заметка о покрытии запрошенных норм («есть ст. 6, 9 — нет ст. 10, 11») вместо голого отказа |
| `VERIFY_V2` | пара «число + единица» обязана опираться на одно предложение документов (подмены «5 рабочих → 5 календарных» невозможны) |
| `RENDER_DET` | детерминированный вывод: обрезка по границе предложения, «Источник: …» при ≥2 ссылках |

Гарантии: verify не пропускает числа/цитаты вне документов; провал → регенерация
с подсказкой → экстрактивный fallback. Ответ **никогда не пуст и не выдумка**;
дедлайн пакета 16 мин соблюдается периодической записью результатов.

## Eval

- `eval/` — локальный раннер по 18 демо-эталонам (`runner.py`), real-LLM
  сравнение (`real_eval.py`), судья по протоколу §1.2 (`judge.py`),
  офлайн-аудит (`history/ANALYSIS.md` — карта «сабмит → состав → балл»
  и измеренный шум судьи ±0.02).
- `eval/traps.jsonl` — 6 ловушек с цитатами-источниками (ложные предпосылки,
  путаница контрагентов, редакции, сроки): материал для регресс-проверок.
- Платформенные результаты: N1 0.274 → v2.1 0.276 → **lean 0.289** (лучший сабмит
  команды); локальный eval 0.738 (17/18 эталонов); real-LLM сравнение 0.943;
  73 автотеста.

## Структура

```
solution.py  pipeline.py  config.py  llm_client.py  ingest.py
retrieval.py guard.py     temporal.py decide.py render.py verify.py reason.py
webapp.py  web/            # веб-чат (фронт без сборки)
data/                      # база знаний + индекс (chunks.jsonl.gz, bm25.index.npz, …)
eval/  tests/  scripts/    # eval, 73 теста, утилиты
docs/                      # контракты, командные роли, скриншоты, исходники презентации

```

**Правило импортов:** только плоские модули корня — никаких подпакетов в коде,
попадающем в сабмит (`scripts/make_submit.py`).

## Известные ограничения

- Только закрытая база; внешние источники не используются.
- Скрытая база платформы поставляется в `data/kb.zip` — в репозиторий не входит.
- «Сегодня» в temporal-логике = дата выгрузки базы (10.10.2026), не системное время.
- Данные демо-контура («Меридиан») — моковые; реальные документы банка в демо не участвуют.
