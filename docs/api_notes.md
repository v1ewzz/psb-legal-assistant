# Заметки о живом API (Фаза 0, DoD)

## Статус офлайн-приёмки 16 ноября

Пробы a–e в этой сессии **не проводились по прямому ограничению пользователя**.
Новые LLM-вызовы, baseline и LLM-judge также не запускались. Пустые результаты
ниже не означают ни успех, ни недоступность API. Получить протоколы уже выполненных
проб у Юсефа/Ильи; при их отсутствии оставить задачу открытой.

Для будущего разрешённого прогона:

- Указывать версию модели из окружения, время, длину входа/выхода, HTTP-статус,
  задержку и лимиты, не публикуя ключи и приватные URL.
- Проба контекста должна обращаться к модели напрямую через клиент; кламп вопроса
  в pipeline может обрезать текст и сделать результат эксперимента недостоверным.
- Для проверки `top_n=8` подать не менее 9 документов. Ответ на двух документах
  не различает свободный top_n и скрытый лимит 2; `probe_all()` этого не доказывает.
- Для скорости фиксировать все пять замеров и объём текста; это не полноценный p95.
- Всплеск запросов ограничивать согласованным лимитом; отсутствие 429 в одном опыте
  не доказывает отсутствие rate limit вообще.
- Проверка `json_object` требует зафиксировать фактический JSON-ответ и ошибки,
  а не только успешный HTTP-статус или удачную починку невалидного ответа.

> Заполняется после проб на реальном прокси. Все «⚠ ПРОВЕРИТЬ» из §21
> закрываются здесь. Решение не должно полагаться на неподтверждённые
> особенности API (огр. 02 кейса).
