## Миссия одной строкой

Ядро §5–15: retrieval → temporal → guard → reason → verify → decide → render + калибровка. Ты владелец качества ответов и дисциплины сабмитов; всё остальное командой разгружено на других.

## Твоя зона в спецификации

| Раздел | Твоя задача |
|---|---|
| §5 Архитектура | `pipeline.py` — `answer_one(question, ctx, deadline)`; dataclass-конвейер (AnalyzeResult → Evidence → TemporalVerdict → ReasonResult → VerifyResult → Zone); правило: между вопросами состояния нет |
| **§6 Схемы данных** | Спроектировать и **заморозить в первый день** (чанк, docs, refs, edges, manifest) — от этого зависит ingestion, web и eval |
| **§7 Ingestion** | Парсеры 21 файла (законы: заголовок/статьи/пункты; документы компании; **допсоглашения как операции**), чанкинг ~800–1100 чанков, edges-граф, CLI `--build-index` |
| §8 Индекс и эмбеддинги | FAISS + bm25s сборка, manifest, контроль совместимости при старте, цепочка деградации §8.3 |
| **§9 Retrieval** | 3 канала (BM25 / dense / exact-ref по реквизитам) + RRF + реранк + расширение через edges; дизамбигуация Альфа-Трейд ≠ Альфа-Трейдинг (rapidfuzz) |
| **§10 Guard** | parse_dialog, **compromised-детектор T1** (инъекция «90 дней» в служебке ЮО-7), Analyze со строгим JSON + repair |
| **§11 Temporal** | Окна редакций valid_from/valid_to, выбор редакции по дате вопроса (Регламент 2023 vs 2025; ДС №1 с 01.10.2024; К-12 с 21.04.2025), арифметика сроков **кодом** (пени, рабочие дни) — не LLM |
| §12 Reason | Промпт, JSON-схема, бюджет ≤2–3 LLM-вызова, контекст ≤8 чанков ≤6000 симв. (до пробы U5) |
| §13 Verify | Детерминированные проверки: подстановка ссылок кодом (D3), все числа ответа найдены в источниках, verify цитат |
| §14 Decide | Confidence-фичи → зоны full/partial/refusal; правило §14.3 «есть supported → не отказываемся»; пороги T_high/T_low |
| §15 Render | Шаблоны эталонного стиля §4.2 (каркасы из demo_output), обрезка ≤10 000, одна строка, без маркдауна |
| §17.2 Метрики | recall@5, доля валидных цитат, две ошибки, ablation-таблица (без реранка/dense/exact-ref/temporal/verify/edges) |
| **§19 Дисциплина** | Лид фаз 1–4; право нажать «сабмит» после зелёного eval + чеклиста §22.2 |

## Артефакты, за которые отвечаешь

- `pipeline.py`, `ingest.py`, `retrieval.py`, `temporal.py`, `guard.py`, `reason.py`, `verify.py`, `decide.py`, `render.py`
- `index/` — все 7 артефактов (chunks.jsonl.gz, docs.json, refs.json, edges.json, emb.npy, bm25.index.npz, manifest.json)
- `eval/runner.py` — метрики (инфраструктура — Юсеф), генератор синтетики по дизайну Никиты
- Калибровка: логрег на 150–300 размеченных, пороги T_high/T_low, тиры full/lite/min по бюджету времени
- JSON-контракт API для Вовы `{answer, status, confidence, sources[], trace{}}` + структура trace
