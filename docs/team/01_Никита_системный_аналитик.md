## Миссия одной строкой

Хранитель правды: реестр ловушек, golden-факты, датасеты eval, требования и приёмка — чтобы ядро отвечало на **проверяемые** факты, а команда не гадала, что «правильно».

## Артефакты, за которые отвечаешь

- `eval/traps.jsonl` — 12+ ловушек: {id, тип, документ, пункт, вопрос-триггер, правильный ответ, неправильный (какой даст бейзлайн)}
- `eval/demo_gold.jsonl` — 18 вопросов: ожидаемый тип §4.4, ожидаемые чанки, ключевые golden-факты
- Дизайн синтетики (100–300 вопросов по 9 категориям §17.1) — спецификация для генератора Ильи
- `docs/api_notes.md` — протокол проб живого API
- `README.md` финального репо (текст) + контент PDF-презентации (дизайн — Иван)
- Отчёты фактчекинга перед сабмитами №2–№5

## Твои фазы

- **Фаза 0** (0.5–1 д): сценарии проб API, старт реестра ловушек и golden-фактов.
- **Фаза 1** (1–1.5 д): чеклист §7.5 по чанкам — найти всё, что парсер порезал неправильно.
- **Фаза 2**: ревью первых ответов минимального пайплайна на 18 демо (стиль §4).
- **Фаза 3**: тесты 12 ловушек; сверка «18 демо = ожидаемый тип ответа».
- **Фаза 4**: рецензия калибровки (две ошибки в порогах), выборка для логрега согласована с реестром.
- **Фаза 6**: README, контент презентации, демо-пакет §18.4, финальный фактчекинг freeze-сабмита.
